El contenido atrae, pero el SEO técnico es lo que permite que los buscadores encuentren, entiendan y muestren tu web correctamente. Un diseño web optimizado cuida estos aspectos desde el primer día, cuando corregirlos es mucho más sencillo que una vez publicada y posicionada. Usa esta lista como guía antes y después del lanzamiento.

1. Rastreo e indexación

  • El archivo robots.txt no bloquea por error páginas importantes.
  • Las páginas que quieres posicionar no llevan la etiqueta noindex.
  • Existe un mapa del sitio (sitemap XML) actualizado y enviado en Search Console.
  • No hay páginas huérfanas: todas reciben al menos un enlace interno.
  • La web está verificada en Google Search Console.

Un fallo habitual en webs nuevas: dejar activada la opción de "disuadir a los buscadores de indexar" que se usa durante el desarrollo.

2. Estructura de URLs

  • URLs cortas, descriptivas y legibles.
  • Sin parámetros innecesarios ni mayúsculas mezcladas.
  • Una sola versión del sitio: con o sin "www", y siempre en HTTPS, con redirecciones 301 hacia la versión elegida.
  • Se usan etiquetas canónicas para evitar contenido duplicado.

3. Códigos de respuesta y redirecciones

  • Las páginas activas devuelven código 200.
  • No hay errores 404 en enlaces internos.
  • Si se migra desde una web anterior, las URLs antiguas redirigen con 301 a su equivalente.
  • Se evitan cadenas de redirecciones.
  • Existe una página 404 útil, con navegación para continuar.

4. Velocidad y Core Web Vitals

  • Imágenes comprimidas y con dimensiones definidas.
  • Carga diferida en imágenes fuera de la primera pantalla.
  • Scripts y estilos optimizados; sin plugins innecesarios.
  • Caché y compresión activadas.
  • Métricas LCP, INP y CLS dentro de los valores recomendados.

5. Versión móvil

  • Diseño adaptable a distintos tamaños de pantalla.
  • Texto legible sin hacer zoom y botones con tamaño suficiente.
  • El contenido de la versión móvil es equivalente al de escritorio.

6. Etiquetas y estructura de contenido

  • Título (title) único y descriptivo en cada página.
  • Metadescripción única y atractiva.
  • Un solo H1 por página, con jerarquía lógica de H2 y H3.
  • Texto alternativo en imágenes relevantes.
  • Enlazado interno con anclas descriptivas.

7. Datos estructurados

  • Marcado de organización o negocio local cuando corresponda.
  • Marcado de preguntas frecuentes, producto o artículo si procede.
  • Validación con las herramientas de pruebas de resultados enriquecidos.

8. Seguridad y fiabilidad

  • Certificado HTTPS válido en todo el sitio.
  • Sin contenido mixto (recursos cargados por HTTP).
  • CMS, temas y plugins actualizados.
  • Copias de seguridad periódicas.

9. Webs multilingües o con varias ubicaciones

  • Etiquetas hreflang correctas si hay varios idiomas.
  • Páginas propias y diferenciadas para cada servicio o ubicación, sin duplicar textos.

10. Medición

  • Analítica instalada y objetivos de conversión configurados.
  • Search Console revisada de forma periódica: cobertura, rendimiento y mejoras.
  • Un rastreo completo del sitio tras el lanzamiento para detectar errores.

En resumen

El SEO técnico no es glamuroso, pero es la base sobre la que se apoya todo lo demás. Una revisión ordenada antes de publicar evita meses de problemas de indexación y rendimiento.
